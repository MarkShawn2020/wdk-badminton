## Credit-Based Pricing

ReelVan uses a simple, transparent credit system:

- **No subscriptions** - Pay only for what you use
- **Credits never expire** - Use them anytime
- **Pay as you go** - Start small, scale up
- **Volume discounts** - Save on larger packages

## How Credits Work

### Credit Calculation

Processing cost depends on:

1. **Video duration** (charged per 5 seconds)
2. **Operations selected** (each has a credit cost)
3. **Video complexity** (complex videos may cost 10-20% more)

### Credit Costs by Operation

| Operation                 | Credits per 5s | USD per 5s |
| ------------------------- | -------------- | ---------- |
| **Watermark Removal**     |
| Standard (Sora, Veo, etc) | 50             | $0.50      |
| Complex/Custom            | 60             | $0.60      |
| **Quality Enhancement**   |
| 720p → 1080p              | 40             | $0.40      |
| 1080p → 1440p             | 50             | $0.50      |
| 1080p → 4K                | 75             | $0.75      |
| Denoise                   | 25             | $0.25      |
| Color Enhancement         | 20             | $0.20      |
| Sharpening                | 15             | $0.15      |
| **Aspect Ratio**          |
| Single conversion         | 25             | $0.25      |
| Multi-format (4 ratios)   | 75             | $0.75      |
| **Custom Watermark**      |
| Add watermark             | 10             | $0.10      |

### Example Calculations

#### Example 1: Simple Watermark Removal

**Video:** 10 seconds, Sora watermark
**Operation:** Watermark removal only

```
Duration: 10 seconds = 2 segments (5s each)
Cost per segment: 50 credits
Total: 2 × 50 = 100 credits ($1.00)
```

#### Example 2: Full Enhancement

**Video:** 30 seconds
**Operations:**

- Remove watermark
- Upscale to 4K
- Denoise (medium)
- Color enhancement

```
Duration: 30 seconds = 6 segments

Per segment:
- Watermark: 50 credits
- 4K upscale: 75 credits
- Denoise: 25 credits
- Color: 20 credits
Total per segment: 170 credits

Total cost: 6 × 170 = 1,020 credits ($10.20)
```

## Maximizing Value

### Tips to Save Credits

1. **Upload high quality sources**
   - Better input = fewer re-processes
   - Saves credits and time

2. **Use presets**
   - Optimized combinations
   - Better than individual operations

3. **Test on short clips first**
   - Process 5-second sample
   - Verify settings before full video

4. **Batch similar videos**
   - Use templates
   - Bulk processing discounts

5. **Buy larger packages**
   - Up to 50% savings
   - Credits never expire

### When to Upgrade

Consider upgrading when:

- Processing regularly (weekly+)
- Need faster turnaround
- Require API access
- Working with long videos (>2 min)
- Need priority support
